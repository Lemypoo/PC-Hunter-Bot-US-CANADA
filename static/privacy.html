Privacy

Item Hunter runs entirely on your own computer. There is no account, no server of ours, no analytics and no tracking.

What is stored

The parts you add, the listings found for them, their price history, the alert feed and your settings. All of it lives in one file, data/state.json, inside the Item Hunter folder. Delete the folder and everything is gone.

What leaves your computer

To check prices, the app opens each store's search page in a hidden browser window, exactly like you would in a normal browser. Those stores see your IP address and the search term, and they set cookies in that hidden browser. The app keeps those store cookies in the data/browser_state files, one per checker, so the stores see the same returning visitor between restarts; delete those files to start fresh. Nothing else is sent anywhere. Turn a store off in Settings and it is never contacted.

Notifications

Windows notifications are produced locally through PowerShell. Optional browser alerts use your browser's own notification permission. Neither involves an outside service.

Optional phone alerts

Both are off until you turn them on in Settings. Email: the app connects to the SMTP server you enter and sends a message containing the part name, the price, the store name and a link to the listing. The SMTP password you enter is stored in plain text in data/state.json on this PC and is never shown again in the browser. Phone push: the same message is posted to the ntfy server you choose (ntfy.sh by default) under your topic name, and the ntfy app on your phone reads it from there. Topics on the public ntfy.sh server are not private, so anyone who guesses the name could read the alerts; the app can generate a random one for you.
